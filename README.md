# To-Do List (Java)

## Description

This is a simple To-Do List program made using Java. It helps the user add tasks, see the tasks and remove tasks when they are completed.

## Features

- Add Task
- View Tasks
- Remove Task
- Exit

## Technologies Used

- Java
- ArrayList
- Scanner

## How to Run

Compile:

javac TodoList.java

Run:

java TodoList
